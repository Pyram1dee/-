# Журнал решений

- База: Zombie Plague 4.3 FIX.
- Архитектура: независимые плагины AMXX.
- Клавиши G/E/R: не перехватывать вслепую; использовать проверяемые бинды и команды.
- Deimos Round 500 HP: требуется уточнение назначения HP.
- Не включать чужие бинарные ресурсы без разрешения.

Добавляй сюда новые подтвержденные решения и открытые вопросы.

## 2026-11-08 — этап 0
- Компилятор: официальный AMX Mod X 1.9 (git5303) с amxmodx.org; хеши в `docs/ENVIRONMENT.md`. Внешние файлы держим в `vendor/`, не коммитим.
- Сборка через `scripts/build.sh`; лог каждой сборки — `build/logs/`.
- Этапы 2–4 не начинаются, пока нет `zombieplague.inc` из ZP 4.3 FIX и рабочего компилятора: по `IMPLEMENTATION_PLAN.md` зависимые компоненты не собираем, пока нет зависимостей, а писать модули вслепую без компиляции запрещает `CLAUDE.md` (п. 1, 8, 9).
- Открытый вопрос: разрешить ли запуск `amxxpc`/SteamCMD/HLDS в этой облачной среде, или собирать локально у пользователя.
- 2026-11-08: компилятор разрешён пользователем через правило `Bash(./scripts/build.sh:*)`; запуск компилятора — только через этот скрипт. `cso_core` собран.
- Заголовок `zombieplague.inc` по памяти не пишем: API должен быть строго из оригинального ZP 4.3 FIX (CLAUDE.md п. 2).
- 2026-11-08: базовая версия API — ZP 4.3 **Fix5a** из комплекта по ссылке пользователя. Fix6a не используем и не смешиваем. На сервер ставим ядро, собранное нашим компилятором из `zombie_plague40.sma`, а не готовый `.amxx` из архива.
- Модули подключают только `zombieplague.inc` Fix5a; ядро ZP не модифицируется.

## 2026-11-08 — этап 2 (классы)
- Общий код в `src/include/cso_common.inc` подключается в каждый плагин; классы остаются независимыми плагинами.
- Клавиши: G = перехват клиентской команды `drop` (у зомби только нож, drop ему не нужен); E/R = фронт нажатия кнопок `IN_USE`/`IN_RELOAD` из usercmd (`pev_button`/`pev_oldbuttons`), сами кнопки не блокируются. Всегда есть `cso_skill` (для бинда) и `/skill`. Перехват отключается `cso_skill_hardkeys 0`.
- Скорость (Predator, замедление Shaman, ловушка Heavy) — post-хук `ResetMaxSpeed` после ядра ZP: множитель поверх значения ядра, после окончания ядро само возвращает штатную скорость. Множители разных плагинов перемножаются.
- Заморозку ZP определяем по гравитации >= 99999 (ядро ставит 999999.9); во время заморозки способности не запускаются.
- Кулдаун отсчитывается от момента активации и сбрасывается при новом заражении и новом раунде.
- Модели гроба/ловушки: `models/cso/coffin.mdl`, `models/cso/zombitrap.mdl`; при отсутствии файла — `models/w_weaponbox.mdl` из базовой CS 1.6 и запись в лог. Модели классов — `zombie_source` из ZP до получения своих.
- CZ-боты не поддерживаются (Ham-хуки на "player" для них не срабатывают); для тестов использовать YaPB/PodBot.
- Все HP/скорости/гравитации классов и значения CVAR — **предложение**, не согласованы.
- Deimos (класс): эффект **предложен** — луч «шок», выбивает оружие в руках; клавиша G предложена. Требует подтверждения.
- Во время Deimos Round способность Deimos выдаётся стартовым зомби на текущую жизнь (native `cso_deimos_grant`); т.к. AMXX останавливает обработку команды на первом плагине с PLUGIN_HANDLED, `cso_zclass_deimos.amxx` загружается раньше остальных классов на G.
