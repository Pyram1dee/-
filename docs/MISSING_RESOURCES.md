## Классы зомби (ТЗ §6 «собственная модель»)
Своих моделей нет ни у одного из 7 классов — временно `zombie_source` из ZP. Нужны модели и когти: Гробовщик (Stamper), Хищник, Невидимка, Шаман, Толстяк, Медсестра, Деймос.
Присланная `zombie_classic.mdl` относилась к стандартному классу ZP, который по ТЗ отключён — назначить одному из 7 классов можно одной строкой в `config/zclass_models.cfg` после согласования.
