# Техническое задание: CSO Zombie 1.6 - Custom Edition

## 1. Цель
Собрать стабильный кастомный Zombie-сервер Counter-Strike 1.6 в стиле Counter-Strike Online. Основа - Zombie Plague 4.3 FIX, НЕ ZA.RU и НЕ REZP. Отдельные модульные AMX Mod X плагины с исходниками `.sma`, настройками, ресурсами и документацией.

## 2. Обязательные принципы
- Поддержка GoldSrc / HLDS / Counter-Strike 1.6, Metamod, AMX Mod X и конкретной проверенной версии ZP 4.3 FIX.
- Сначала определить совместимые версии и зафиксировать их в документации, не выдумывать номера версий.
- Не изменять стандартные игровые файлы клиента без необходимости.
- Ресурсы скачиваются только из законных источников или предоставляются владельцем; исходные архивы проекта пока отсутствуют.
- Никаких ложных обещаний о готовой сборке: каждый плагин должен компилироваться и тестироваться на HLDS.

## 3. Классы зомби
| Класс | Способность | Желаемая клавиша | Требования |
|---|---|---|---|
| Гробовщик | Создание гроба | G | Ставить объект на допустимой поверхности, лимит активных объектов, время жизни, cooldown |
| Хищник | Ускорение | G | Временный speed boost, восстановление скорости после окончания/смены состояния |
| Невидимка | Невидимость ~15 секунд | G | Настраиваемая прозрачность, корректное восстановление модели/рендера |
| Шаман | Крик | E | Радиусный эффект с балансируемыми параметрами; исключить повторное срабатывание use |
| Heavy Zombie / Толстяк | Ловушка | R | Лимит ловушек, очистка при конце раунда, защита от застревания |
| Медсестра | Изменение гравитации | R | Временный эффект и гарантированный reset |
| Deimos | Специальная способность | TBD | Выделенный модуль; уточнить эффект по оригинальному архиву/референсу |

Примечание: клавиши G/E/R в CS 1.6 - это клиентские бинды, а не универсальные серверные события. Сделать команды `say /skill`, `+cso_skill`/`-cso_skill` или совместимые бинды, а прямое управление клавишами подключать только после проверки механики GoldSrc. Не ломать стандартные drop/use/reload.

## 4. Специальные раунды
- Deimos Round: обсуждавшийся вариант с 500 HP. Неясно, относится ли 500 HP к каждому Deimos или к особому персонажу; вынести в CVAR и подтвердить перед балансировкой.
- Сохранить совместимость с базовыми режимами ZP, исключить одновременный запуск конфликтующих режимов.
- Показать HUD-уведомления и корректно сбрасывать способности/объекты после раунда.

## 5. Human Shop
- Отдельное меню для людей с категориями оружия/предметов.
- Интеграция Poison Launcher 1.8.1 из пользовательского архива `9778_-_amxx_public_poison_launcher_1.8.1.rar` после проверки лицензии, исходников и API.
- Проверка: доступен только человеку, достаточно валюты, нет дублирования покупки/выдачи, корректная выдача оружия.
- Валюта по умолчанию - ammo packs ZP, если версия API поддерживает; иначе адаптер.

## 6. VIP
- VIP-права через проверенную AMXX систему доступа, настройки прав и выдачи предметов.
- VIP Hammer: повышенная скорость, измененная гравитация, урон и отбрасывание; дополнительная усиленная отдельная атака НЕ нужна.
- Значения всех бонусов - через CVAR, предотвращать конфликт с эффектами классов.

## 7. Ресурсы
- Модели, звуки, спрайты и HUD с manifest-файлом, контроль существования и precache.
- Архив `heavy_zombie.zip` ранее содержал Source-форматы `.mdl/.vvd/.vtx/.phy/.vmt`; нельзя просто скопировать их в CS 1.6. Нужна законная конвертация/замена совместимыми GoldSrc моделями.
- В данном ZIP нет исходных сторонних ресурсов и готового HLDS.

## 8. Качество
- Логи ошибок, CVAR-настройки, отсутствие утечек сущностей, восстановление состояния игрока после смерти, отключения, смены команды/раунда.
- Проверки: 1 игрок, 2 игрока, 16+ ботов/клиентов при наличии тестового окружения; повторные смены раундов, mapchange, reconnect.
- Целевые показатели производительности установить после замера базовой сборки.

## 9. Результат, который должен подготовить Claude Code
1. Рабочий HLDS на законно полученной базе и зафиксированные версии зависимостей.
2. Компилируемые `.sma`, соответствующие `.amxx`, конфиги, инструкции установки и обновления.
3. Отдельные плагины классов, Human Shop, VIP Hammer, Deimos Round, интеграционный адаптер Poison Launcher.
4. Проверка логов, тест-кейсы, таблица конфликтов, итоговый ZIP релиза без неразрешенных сторонних материалов.

## 10. Что пока не подтверждено
Точные характеристики классов, стоимость товаров, точный эффект Deimos, права VIP, версии AMXX/HLDS и сами оригинальные архивы. Claude должен предложить значения по умолчанию с пометкой «предложение», а не выдавать их за ранее согласованные.
