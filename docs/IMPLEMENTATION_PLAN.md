# Порядок разработки для Claude Code

## Этап 0 - аудит
- Найти HLDS, Metamod, AMXX, ZP 4.3 FIX, Pawn compiler и include-файлы.
- Проверить легальность и совместимость имеющихся ресурсов.
- Создать `docs/ENVIRONMENT.md` с фактическими версиями и путями.
- Если зависимостей нет, написать инструкции получения и остановить сборку зависимых компонентов.

## Этап 1 - минимальный сервер
- Установить и запустить HLDS с ZP 4.3 FIX.
- Скомпилировать `src/cso_core.sma`, подключить через `plugins-cso.ini`.
- Проверить консоль, логи и загрузку карты.

## Этап 2 - классы
- Реализовать независимые модули по одному: Predator, Invisible, Undertaker, Shaman, Heavy, Nurse, Deimos.
- Регистрация классов через ZP API, проверка класса/состояния до способности.
- Клавиши: серверные команды + инструкция клиентских биндов.
- После каждого класса компиляция, тест и запись результата.

## Этап 3 - раунды и магазин
- Deimos Round с параметрами CVAR и безопасным запуском.
- Human Shop и интеграция Poison Launcher после получения архива.

## Этап 4 - VIP
- VIP Hammer без альтернативной усиленной атаки.
- Совместимость с обычным оружием, покупками и режимами.

## Этап 5 - контент и релиз
- Проверить модели GoldSrc, precache, звуки, спрайты, пути и регистр букв Linux.
- Провести регрессионные тесты, проверить падения/логи, собрать релиз.

## Критерии готовности
- Все `.sma` собираются установленным компилятором без ошибок.
- Сервер запускается и меняет карты без падений.
- Классы работают без постоянных эффектов после смерти/смены класса.
- Магазин не выдает оружие бесплатно или дважды.
- Логи не содержат повторяющихся runtime ошибок.
- Указаны отсутствующие ресурсы и нерешенные вопросы.
