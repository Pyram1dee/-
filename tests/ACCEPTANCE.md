# Приемочные тесты

- [ ] HLDS запускается с нужной картой, ZP 4.3 FIX загружен.
- [ ] `amxx plugins` не показывает ошибок загрузки.
- [ ] Команда `/cso` выводит подтверждение загрузки ядра.
- [ ] Каждый класс выбирается и способность срабатывает только при нужном состоянии.
- [ ] Все временные эффекты сбрасываются после смерти, смены класса, отключения и конца раунда.
- [ ] Нет зависших гробов/ловушек и постоянного изменения скорости/гравитации.
- [ ] Deimos Round не конфликтует с другими раундами.
- [ ] Human Shop корректно списывает валюту и выдает товар.
- [ ] Poison Launcher работает после подключения предоставленного архива.
- [ ] VIP Hammer не имеет лишней усиленной атаки.
- [ ] Отсутствуют ошибки precache, missing models/sounds и AMXX runtime errors.
- [ ] Повторные mapchange/reconnect не приводят к падению сервера.
