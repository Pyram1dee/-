# Этап 4 — чек-лист VIP Hammer (ручной, на HLDS)

Статус: **не выполнен** — HLDS ещё не запускался.
Подготовка: в `users.ini` выдать тестовому игроку флаг `t` (или значение `cso_vip_flag`).

- [ ] Не-VIP: обычный нож, нет бонусов, `/hammer` → «только VIP».
- [ ] VIP человек с ножом: скорость × `cso_vip_hammer_speed_multiplier`, гравитация × `cso_vip_hammer_gravity_multiplier`.
- [ ] Смена на огнестрел: скорость и гравитация обычные; обратно на нож — бонусы снова.
- [ ] Урон ножом по зомби × `cso_vip_hammer_damage_multiplier`; зомби отбрасывает.
- [ ] Правая кнопка (усиленный удар) ничего не делает при `cso_vip_hammer_block_attack2 1`.
- [ ] VIP заражён с ножом в руках → гравитация зомби-класса, не человеческая×0.85.
- [ ] VIP стал выжившим → бонусов нет.
- [ ] `/hammer` выключает/включает молот; после реконнекта снова включён.
- [ ] Покупки в Human Shop и стандартный buy работают как у всех.
- [ ] Модели `v_hammer`/`p_hammer` есть → показываются; нет → нож, предупреждение в логе один раз.

## Модели (клиент CS 1.6)
- [ ] Клиент скачивает `models/cso/*.mdl` при входе (sv_allowdownload 1), без ошибок `Bad model` / краша.
- [ ] Гроб стоит на полу, не утопает и не висит; хитбокс совпадает с видимой моделью.
- [ ] Ловушка лежит на земле, полупрозрачная (`cso_heavy_trap_alpha`).
- [ ] v_hammer: idle/draw/удары воспроизводятся, молот справа, не перекрывает прицел.
- [ ] p_hammer: у других игроков молот в правой руке, ориентация нормальная на моделях людей CS.
