# Этап 2 — чек-лист классов зомби (ручной, на HLDS)

Статус: **не выполнен** — HLDS ещё не запускался. Все пункты проверить на сервере.

Подготовка: `zp_zombie_classes 1`, в консоли клиента `bind g cso_skill` (для E/R не требуется).
`sv_maxspeed` должен быть >= скорости Хищника в ускорении (250 * 1.3 = 325 → `sv_maxspeed 400`).

## Общее для всех классов
- [ ] Класс виден в меню классов ZP (`zp_zombieclasses.ini` дописан автоматически).
- [ ] Способность не работает у человека, немезиды, другого класса, мёртвого.
- [ ] Способность не работает в заморозке (frost-граната ZP).
- [ ] Кулдаун: повтор раньше срока → сообщение с остатком секунд.
- [ ] `cso_skill_hardkeys 0` → G/E/R не перехватываются, работает только `cso_skill` и `/skill`.
- [ ] У людей `drop`, `+use`, `+reload` работают как обычно.
- [ ] После смерти, очеловечивания (антидот), отключения, конца раунда эффект снят.

## Predator (G)
- [ ] Скорость растёт в `cso_predator_speed_multiplier` раз на `cso_predator_duration` с.
- [ ] После окончания — штатная скорость класса; смена оружия не сбрасывает и не продлевает ускорение.

## Invisible (G)
- [ ] Прозрачность `cso_invisible_alpha` на `cso_invisible_duration` с; при `zp_set_modelindex_offset` / отдельной модели — тоже.
- [ ] Заморозка во время невидимости → после разморозки невидимость вернулась (если не истекла).
- [ ] После окончания рендер обычный.

## Undertaker (G)
- [ ] Гроб ставится перед игроком на полу; не ставится на крутом склоне, в стене, в человеке.
- [ ] Лимит `cso_undertaker_max_coffins`: старший гроб удаляется (`cso_undertaker_replace_oldest 1`) или отказ (0).
- [ ] Через `cso_undertaker_lifetime` с гроб исчезает; люди ломают выстрелами, зомби — нет.
- [ ] Владелец не застревает в своём гробу. Конец раунда/выход владельца — гробы удалены.

## Shaman (E)
- [ ] Удержание E не повторяет крик; двери по E открываются.
- [ ] Люди в радиусе и в прямой видимости: тряска, затемнение, замедление; за стеной — нет.
- [ ] Замедление снимается через `cso_shaman_slow_duration` с, при заражении и в конце раунда.

## Heavy (R)
- [ ] Ловушка ставится только на земле, лимит `cso_heavy_max_traps`, дистанция `cso_heavy_trap_spacing`.
- [ ] Человек обездвижен на `cso_heavy_trap_hold` с, ловушка исчезает; зомби ловушку не активируют.
- [ ] Двое одновременно наступили — сработала один раз.
- [ ] Конец раунда / выход владельца — ловушки удалены, пойманные освобождены.

## Nurse (R)
- [ ] Гравитация умножается на `cso_nurse_gravity_multiplier` на `cso_nurse_duration` с, затем возвращается.
- [ ] Заморозка до конца эффекта → после разморозки гравитация штатная, а не пониженная.

## Deimos (G, эффект — предложение)
- [ ] Луч виден; у задетого человека выпадает основное оружие/пистолет; нож и гранаты не выпадают.
- [ ] Выживший не затрагивается при `cso_deimos_affect_survivor 0`.
