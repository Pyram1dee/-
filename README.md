# CSO Zombie 1.6 - Custom Edition

Стартовый пакет для Claude Code: полное ТЗ, поэтапный план, инструкции для агента, структура проекта, шаблон AMXX-плагина, конфиг и проверки. **Это не готовый игровой сервер.**

## Как начать
1. Распакуй ZIP в отдельную папку.
2. Открой эту папку через Claude Code.
3. Напиши: `Прочитай CLAUDE.md и docs/TECH_SPEC_RU.md. Начни с этапа 0, проверь окружение, затем реализуй этап 1. Не заявляй о работоспособности без компиляции и тестов.`
4. При наличии положи свои законно полученные HLDS/ZP/AMXX файлы в локальную папку `vendor/` (игнорируется Git).
5. Добавь архивы Poison Launcher и heavy_zombie в `vendor/` для аудита, если они у тебя сохранились.

## Состав
- `CLAUDE.md` - постоянные инструкции Claude Code.
- `docs/TECH_SPEC_RU.md` - требования и функциональность.
- `docs/IMPLEMENTATION_PLAN.md` - порядок работ.
- `src/cso_core.sma` - минимальный исходник плагина.
- `config/plugins-cso.ini` - список плагинов.
- `config/cso_custom.cfg` - начальные CVAR-настройки (значения предлагаемые).
- `scripts/check_project.py` - проверка структуры.
- `tests/ACCEPTANCE.md` - чек-лист приемки.

## Ограничения
Ни исходные игровые архивы из старого проекта, ни модели, ни готовые AMXX-файлы в комплект не включены. Они должны быть получены и проверены отдельно.
